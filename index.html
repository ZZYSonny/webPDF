Every page is rendered to SVG. Fonts embedded in the document — including the Type 1 (PFB/PFA) faces LaTeX produces, which browsers cannot use directly — are rebuilt from MuPDF's own outlines into web fonts, so the SVG carries selectable text that references a real font, and only falls back to outlines where that is not provably safe.
